How Pneuma works


A program is a list of lines. let gives a value a name, and the last expression is the result, shown after ⇒. Everything is an expression and nothing changes once it exists: there are no loops and no variables to update. You repeat work with recursion, and you transform lists with map, filter and fold. Comments start with --.


let greeting = "hello"
let n = 3 * 4          -- 12
greeting + " " + show(n)


Values and operators


Numbers (3, 2.5), strings ("text"), booleans (true, false) and lists ([1, "two", 3]). From tightest to loosest: * / %, + - (+ also joins strings and lists), < > <= >=, == !=, &&, ||, then the pipe |>.


Functions


Write x -> body for one parameter or (a, b) -> body for several, and call with parentheses. Give a function fewer arguments than it needs and you get back a function waiting for the rest (currying). Functions can return functions and remember the names around them (closures).


let add = (a, b) -> a + b
let inc = add(1)       -- still needs b
inc(41)                -- 42


Pipelines


x |> f means f(x). x |> f(a) means f(a)(x), so the piped value always becomes the last argument. That is why built-ins take the list last: map(f, xs), filter(p, xs). A pipeline can continue on the next line when that line starts with |>.


range(1, 6) |> map(x -> x * x) |> sum   -- 55


Choices and local names


if cond then a else b is an expression, and else is required. let name = value in body creates a name that exists only inside body. Lines may break after then, else, in, ->, = or any operator, and before then, else and in.

Files


Programs are plain text with the .pneuma extension. Open loads a file into the editor (you can also drop one onto it). Save downloads the editor's text under the name in the box.


Common errors


Undefined name: a typo, or the name is defined further down. Not a function: you called something that is a value. Expected "else": every if needs both branches. Too much recursion: the function never reaches its base case, or the input is very large.




Values: numbers, strings, true/false, lists. Functions: x -> x + 1, (a, b) -> a + b, curried automatically. Flow: xs |> map(f) |> sum. Open the Guide for the full reference.
